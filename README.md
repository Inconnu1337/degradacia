# Ночной рубеж

Штабная игра о воздушной войне вымышленного края. Вся логика на сервере, браузер только рисует и отправляет команды.

Версия: **2.5.0** (`GAME_VERSION` в `shared/config.js`, совпадает с `package.json`).

**Режимы:** Оборона (против ИИ), Налёт (против ИИ), **Дуэль** — сетевая игра ПВО против налёта. На одну сторону можно зайти вдвоём и больше (ссылка «Напарник»). Сколько угодно **наблюдателей** (ссылка «Зрители» или «Смотреть» по коду): видят всю партию без тумана войны, но ничего не могут.

## Запуск

```
npm install
npm start          # http://localhost:8080  (порт — переменная PORT)
npm test           # прогон правил + сквозной тест двух браузеров
```

## Развёртывание (Render)

New → Web Service → репозиторий. Build: `npm install`, Start: `npm start`.
Vercel не подходит: нужен постоянный процесс с WebSocket. Партии живут в памяти — перезапуск их обнуляет.

## Устройство

```
server/   HTTP + WebSocket, комнаты (по песочнице vm на партию)
game/     правила: симуляция, режимы, команды сторон, снимки «глазами стороны»
shared/   данные, карта, чистые функции — общие для сервера и клиента
client/   отрисовка, интерфейс, звук (Web Audio, без файлов)
test/     headless.js — кампании ботами; e2e.js — сервер + два клиента в jsdom
tools/    balance.js — прогон баланса дуэли ботами
```

Сохранение: 💾 днём и ночью скачивает файл с полным состоянием (обе стороны, журналы, цели в воздухе). Ночная партия открывается на паузе. Загрузка — в меню, создаётся новая партия с новым кодом.
Файл содержит и скрытые данные соперника — в дуэли сохраняйте у того, кому доверяете.

Ключевые файлы: `game/commands.js` (что может приказать сторона), `game/views.js` (что сторона видит — туман войны),
`game/core/bridge.js` (время, паузы, события), `shared/data/launch.js` (пусковая логистика налёта),
`shared/data/weather.js` (погода), `game/data/phrases.js` (варианты радиообмена), `game/sim/enemy/carriers.js` (носители и ложная активность),
`game/sim/damage.js` (пожары, пожарные, ремонт под огнём), `game/save.js` (сохранение).
